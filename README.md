# Youtube_Remake

A full-featured dark-mode video streaming platform built with React, TypeScript, Tailwind CSS, Express, and Firebase.

## Features

- **Home Feed & Category Filtering**: Responsive video grid with hover previews, duration badges, and category chips.
- **Shorts Player**: Full-height vertical short-form video feed with comments, likes, and creator navigation.
- **Watch Page & Theater Mode**: Interactive video player, ambient glow toggle, expandable descriptions, and real-time comments.
- **Creator Channels & Subscriptions**: Customizable channel profiles, subscriber counts, copyable creator usernames, and subscription management.
- **Super Admin Panel**: Manage creators, customize subscriber/view/like counts, ban/unban accounts with duration controls, and moderate platform content.
- **Discord Community Integration**: Direct one-click access to the community Discord server (`https://discord.gg/NZ2p8V9qtQ`).

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
